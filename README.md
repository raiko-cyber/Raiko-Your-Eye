# Raiko-Your Eye

ИИ-помощник для слепых и слабовидящих людей. Телефон смотрит через камеру и голосом рассказывает, что перед человеком. Управлять можно голосом, на казахском, русском или английском.

Это веб-приложение: оно открывается по ссылке в браузере телефона и ставится на главный экран как обычное приложение.

## Что умеет

- **Что вокруг?** Описывает обстановку, сначала называет препятствия.
- **Прочитать текст.** Читает вывески, документы, упаковки, ценники.
- **Что это за предмет?** Называет предмет, надпись на этикетке, номинал купюры.
- **Где я?** По GPS называет место, улицу и номер дома, район и город, а ещё точность в метрах. Ближайшие переходы и остановки пока **не** называет, компас не используется.
- **Вопрос голосом или текстом.** Можно спросить что угодно о том, что видит камера.
- **Голосовые команды:** «что вокруг», «прочитай», «что это», «где я», «повтори», «стоп», «переключи камеру». По-казахски: «айналамда не бар», «оқы», «бұл не», «мен қайдамын», «қайтала», «тоқта», «камераны ауыстыр».
- **Звуки и вибрация:** сигнал и короткая вибрация, когда приложение начинает смотреть, двойной сигнал перед ответом, тихий сигнал после ответа, низкий сигнал и длинная вибрация при ошибке.

По умолчанию снимает задняя камера, кнопкой или голосом можно переключить на переднюю. Местоположение к вопросам о картинке **не** добавляется: на вопрос «на какой я улице?» отвечает только команда «где я».

ИИ-модель: по умолчанию gemini-3.5-flash-lite, она отвечает за несколько секунд. Если она перегружена или молчит дольше 15 секунд, сервер сам пробует gemini-3.5-flash, потом gemini-3.8-flash.

## Что нужно, чтобы запустить

1. **Node.js** версии 18 или новее (бесплатно, с сайта nodejs.org, версия LTS).
2. **Ключ Gemini API.** Его создают в Google AI Studio (aistudio.google.com), в разделе API keys, под обычным аккаунтом Google. У Gemini есть бесплатный уровень с ограничением числа запросов в минуту и в день. На бесплатном уровне Google может использовать отправленные данные для улучшения своих продуктов. Цены и лимиты: https://ai.google.dev/pricing

   При желании вместо Gemini можно подключить Claude (платно): в `.env` вписывают `ANTHROPIC_API_KEY` вместо ключа Gemini.

## Запуск на компьютере (в VS Code)

1. Откройте эту папку в VS Code: File → Open Folder.
2. Сделайте копию файла `.env.example` и назовите её `.env`.
3. В файле `.env` впишите свой ключ после `GEMINI_API_KEY=` и сохраните.
4. Откройте терминал (Terminal → New Terminal) и выполните:

   ```
   node server.js
   ```

5. Откройте в браузере http://localhost:3000 и разрешите доступ к камере и микрофону.

Чтобы остановить, нажмите в терминале Ctrl+C.

## Как открыть на телефоне

Камера, микрофон и геолокация в браузере телефона работают только по защищённому адресу (`https://...`). Если открыть адрес компьютера по домашнему Wi-Fi (`http://192.168...`), они не включатся. Есть два способа.

### Способ 1. Быстро проверить (компьютер должен быть включён)

1. Запустите приложение: `node server.js`.
2. Во втором терминале выполните:

   ```
   npx cloudflared tunnel --url http://localhost:3000
   ```

3. В терминале появится адрес вида `https://что-то.trycloudflare.com`. Откройте его на телефоне.

Ссылка работает, пока на компьютере открыты оба терминала. При каждом запуске адрес новый.

### Способ 2. Постоянно, без компьютера (Render, бесплатно)

1. Загрузите папку проекта на GitHub, **без файла `.env`** (он уже указан в `.gitignore`).
2. На render.com: New → Blueprint → выберите этот репозиторий. Файл `render.yaml` всё настроит сам.
3. Когда Render попросит `GEMINI_API_KEY`, вставьте свой ключ.
4. Через пару минут появится адрес `https://raiko-your-eye.onrender.com` (или похожий).

На бесплатном тарифе Render «засыпает», если приложением долго не пользуются, и первый запрос после этого идёт около минуты.

### На телефоне

Откройте ссылку в Chrome (Android) или Safari (iPhone) и разрешите **камеру, микрофон и геолокацию**. Потом: меню → «Добавить на главный экран», и приложение будет открываться как обычное. На iPhone компас включается после первого нажатия любой кнопки: разрешите «Движение и ориентация».

## Как устроено

| Файл | Зачем |
| --- | --- |
| `server.js` | Сервер. Отдаёт страницу и пересылает кадр с камеры ИИ-модели. Ключ хранится только здесь. |
| `public/index.html` | Само приложение: камера, кнопки, голос. |
| `public/sw.js`, `public/manifest.webmanifest`, `public/icon-*.png` | Нужны, чтобы приложение ставилось на главный экран. |
| `.env.example` | Образец настроек. Свой ключ пишите в `.env`. |
| `render.yaml` | Настройки для хостинга на Render. |

## Что важно знать

- **Ключ никому не показывайте** и не выкладывайте файл `.env` в интернет.
- **Голос на казахском** зависит от телефона: приложение использует встроенный голос устройства. Если казахского голоса на телефоне нет, приложение читает казахский текст русским голосом и один раз предупреждает об этом. Проверьте это на своём телефоне.
- **Защита ключа:** не больше 20 запросов в минуту с одного телефона и 60 в минуту на всех вместе (`RATE_LIMIT_PER_MIN`, `GLOBAL_LIMIT_PER_MIN`).
- **Распознавание голоса** работает в Chrome на Android и на компьютере. В других браузерах кнопки микрофона может не быть; вопрос тогда можно написать.
- **Геолокация.** По кнопке «Где я?» координаты уходят на ваш сервер, а с него в OpenStreetMap (Nominatim) за адресом. В ИИ координаты не отправляются. Nominatim бесплатный, но рассчитан на небольшую нагрузку (около одного запроса в секунду). Для прототипа хватит, для сотен людей нужен свой сервер карт или платный сервис (адрес меняется в `.env`: `GEOCODER_URL`).
- **Точность GPS** в городе 5–30 м, между высокими домами и в помещении хуже. Карта OpenStreetMap в Казахстане местами неполная: перехода или остановки может не быть в данных.
- **Очки Meta** пока не подключены.
- Приложение работает по кадру в момент нажатия или команды, а не описывает видео непрерывно.
- Это прототип. Он не заменяет трость и собаку-проводника.
